Stage 2.1: Initial Explorations of the Dataset.

Note

This example captures my own real, work-in-progress thinking about this dataset. I haven’t gone back and made any revisions. I am writing this page at the same time as I’m asking these questions. What is in this dataset? What kinds of questions might I want to ask as I drill down?

About

Dataset

The dataset is Executions in the United States, 1608 - 2002: The Espy File. It is stored in the _data folder, and the entire set of downloaded files from ICPSR is in the folder ICPSR-08451. Below, you’ll see that I’m using inscrutable column names. They are labled in the file projects/demo/_data/ICPSR_08451/DS0001/08451-0001-Codebook.pdf

Research Question

My initial research question is pretty vague – “Are there trends in the crimes for which people have been executed in the United States?” And if I’m being honest, this isn’t the right question for someone with both my disciplinary background and my technical skillset/interests. I’m more interested in how this dataset is shaped, and what I might learn from the kinds of values I’m seeing in it. (This is a more inductive approach.)

First question: gender

I notice that there is a field that defines the sex of the person. What’s the gender breakdown within this dataset?

import pandas as pd
from pyprojroot import here # this helps us navigate tricky path stuff between local runs and quarto builds

# Load the data using here() with the path from the project root
file_path = here("projects/demo/_data/ICPSR_08451/DS0001/08451-0001-Data.tsv")
df = pd.read_csv(file_path, sep='\t')  # Remember!! use '\t' for tab-separated (which this data is)

# how many people executed were women? (where V19 = 2)
count_v19 = len(df[df['V19'] == '2']) # NOTE - this column is a varchar, so you need to put quotes around your integer. 

# total rows in dataset
total_rows = len(df)

# lil percent count
gender_breakdown = count_v19 / total_rows * 100

print("Number of women: ", count_v19)
print("Total Rows ", total_rows)
print(f"Percentage of women: ",  gender_breakdown)
Number of women:  364
Total Rows  15268
Percentage of women:  2.384071260151952

At this point, I know that 364 women (2.38%) of all people executed in this dataset were women. Within those 364, what else can I learn?

Trigger warning!

Based on what we’re seeing here (and some browsing I’m doing in the explorer), it looks like the majority of women executed were executed during slavery in the United States. Let’s see what the median year in this dataset is - does this make sense?

median_year = women['V14'].median()
print(median_year)
1826.5

Okay, the median year is 1826. (Remember, the 13th Amendment which constitutionally abolished slavery was in 1856) This validates the occupation data we’re seeing. Slave Revolt?

We’re seeing data that matches historical expectations (though we must always be careful when making these!). Women executed for witchcraft were exclusively white in the dataset. I would similarly expect women convicted of “Slave Revolt” to be Black. Does this track?

1741

Okay, something happened in 1741 with Margaret Kerry and SArah Hughson (I’m guessing). A quick web search of these two names reveals (1) A website called “executedtoday.com” (grim), with details of this situation. It was apparently part of the “New York Slave Rebellion of 1741” (Brittanica Entry)

If this dataset is complete, I would expect to see a lot of people executed in New York (state == 36) in 1741. The Brittanica entry reads “As a result of the rumors, false confessions, and finger-pointing, approximately 30 Black people and 4 white people (the Hughsons, Kerry, and Ury) were executed, and some 80 more people, mostly Black but some white, were exiled.” Does the dataset have this data?
