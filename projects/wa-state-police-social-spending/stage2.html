2. How many offenses were violent and how many were nonviolent?

Now I’m going to use the ‘crime_2025_clean’ data that lists all offenses to sum by violent and nonviolent crime.

#let's see all of the offenses
crime_2025_clean["Offense"].unique()

#now I'll divide based on FBI UCR definitions of violent & other crime
violent_offenses = [
    "Murder Non Negligent Manslaughter",
    "Rape",
    "Robbery",
    "Aggravated Assault"]

#sorting into violent and other
crime_2025_clean["Crime Type"] = np.where(
    crime_2025_clean["Offense"].isin(violent_offenses),
    "Violent",
    "Other")

#sum types of crime by county
county_crime_type = (crime_2025_clean
    .groupby(["County", "Crime Type"])
    .size()
    .unstack(fill_value=0)
    .reset_index())

#see violent, other, and total all in one df
county_crime_type["Total Offenses"] = (
    county_crime_type["Violent"] +
    county_crime_type["Other"])

#drop 'State Agency' in this df too
county_crime_type = county_crime_type[county_crime_type["County"] != "State Agency"]

#county_crime_type

Deciding how to define “violent crime” in this case was difficult because the offenses listed in this dataset are not specific. I initially wanted to use Washington state law’s definition of a violent offense, but it defines violent crime by degree. For example, rape in the first degree is classified as a violent offense but rape in the second degree is not (Source). My data simply lists ‘Rape’, so I don’t feel that I have the ability use the Washington state legal definition without proper specification. I insteaed defined violent crime using the common crime statistics defintion, which is based on the FBI’s Uniform Crime Reporting defintion. UCR lists the following as violent offenses (no matter the degree): murder and nonnegligent manslaughter, rape, robbery, and aggravated assault. I choose to label the categories “Violent” and “Other” because crimes that don’t fall into the FBI’s definition of violent crime are not necessarily nonviolent.
